# Покер вдвоём ♥

Техасский холдем один на один в браузере. Сервер не нужен: игроки соединяются напрямую через WebRTC (PeerJS).

## Как играть
1. Открой сайт и нажми «Создать стол».
2. Отправь ссылку сопернику.
3. Как только второй игрок сядет за стол, начнётся игра.

Хозяин стола не закрывает вкладку (перезагружать страницу можно, игра сохранится).
